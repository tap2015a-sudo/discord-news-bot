# Discord Basic Bot

بوت ديسكورد تجريبي بـ JavaScript وdiscord.js v14.

## الأوامر
- /ping
- /help
- /avatar
- /userinfo
- /serverinfo

## متغيرات البيئة المطلوبة
- DISCORD_TOKEN
- CLIENT_ID
- GUILD_ID

## التشغيل
1. ثبّت المكتبات: `npm install`
2. سجّل الأوامر: `npm run deploy`
3. شغّل البوت: `npm start`

لا تضع التوكن داخل الكود أو GitHub.
